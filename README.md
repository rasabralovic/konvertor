# Konvertor jedinica

Jednostavan CLI program u C++ za pretvaranje mernih jedinica.
Projekat sluzi kao vezba za rad sa Git-om.

## Podrzane konverzije

- Celzijus ↔ Farenhajt
- Kilometri ↔ milje
- Kilogrami ↔ funti
- Litri ↔ galone

## Zahtevi

- g++ (C++17)
- make

## Pokretanje

```bash
make        # kompajlira u build/konvertor
make run    # kompajlira i pokrece
make clean  # brise build folder
```
